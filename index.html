📋 全流程指引

从入驻到上架销售的完整流程，共 9个步骤。

📌 流程概览图

📝 详细流程说明

1、商家发布商品
治理审核是否 同款过多重复铺货？
• 是 → 发布商品失败，需重新换图换标重新上架
• 否 → 继续判断是否免审店铺

2、是否免审店铺
• 是 → 主SKU进入待审价状态，其他SKU进入核价状态（主SKU未进入核价状态，其他SKU不会出价格）
• 否 → 继续判断是否需要套版

3、是否需要套版
• 是 → 进入 寄样审版 流程
• 否 → 直接进入核价

4、寄样审版
• 审版合格 → 进入核价
• 审版不合格 → 按审版建议修改后，点重新寄样 → 送货上门找对应买手
注意：吊牌、工艺、尺码等不符合要求会导致审版不合格

5、核价
核价通过后，系统判断是否已抓取到 低价同款：
• 是 → 成功上架
• 否 → 继续进入图审

6、图审
图审通过后判断 价格是否满意：
• 价格满意 → 成功上架
• 价格不满意 → 作废，上新失败

7、下首单发货
图审成功后进入发货流程

8、入库质检
• 质检合格 → 成功上架
• 质检不合格 → 找小二申诉
质检不合格常见原因：图物不符、克重不符、尺码不符、各规格参差问题

9、发货前自检（重要！）
• 商品包装袋上需要有 合规标签
• 实物图需上传到商家后台实物图页面系统审核，审核通过无异常即为没问题
• 发货前自检 图物是否一致、尺码是否一致、重量是否符合要求

📝 标题与视觉优化

通过优化标题关键词和视觉呈现，命中流量关键词、获得曝光并提升点击率（CTR），从而提升转化率。

上图说明了搜索流量与推荐流量的核心差异：搜索流量靠标题堆砌关键词截流刚需消费，推荐流量靠主图视觉3秒吸睛激发冲动消费。

🔑 一、标题优化万能公式

标题六大维度：
品牌名 + 节日词 + 风格 + 面料材质 + 款式类型 + 核心卖点 + 适用场景/季节

节日词参考：Christmas、Halloween、Thanksgiving、Valentine's Day、Father's Day
风格参考：复古学院、运动风、工装机能、连衣户外、轻熟通勤

覆盖得越完整、越贴合商品本身，越有机会获得稳定的搜索和推荐流量。

📊 二、长尾词挖掘三步法

Step 1：长尾词挖掘 — 找到买家实际搜索的关键词组合
Step 2：商品分析 — 分析竞品标题中的维度覆盖情况
Step 3：AI工具应用 — 用ChatGPT等AI工具结合关键词公式生成标题

📋 标题示例：

Men's Heritage Harrington Jacket Plaid Lining Full Zip Smart Casual Outerwear for Spring Fall
↓ 长尾词拆解：男(Men's) + 品类(Jacket) + 核心卖点(Heritage/Plaid Lining/Full Zip) + 风格(Smart Casual) + 适用场景/季节(Spring Fall)

👁 三、视觉优化SOP总览

核心问题：什么图好卖？真人图好还是非真人图好？不同品牌/人群/国家应该怎么看？AI图片怎么做更真实？

四大优化方向：
① 拍摄图与商品详情页规范
② 不同视觉的转化作用
③ 非人视觉优化思路
④ AI图片生成方法

🏪 四、店铺视觉差异化与风格统一化

好的店铺案例有两种做法：

① 差异化路线：不同人像、不同姿势、不同背景，打造丰富的视觉模板
② 统一化路线：统一风格、统一色调、统一背景，打造统一的视觉模板

在保持店铺整体风格统一的前提下，通过模特和背景的差异化来提升视觉吸引力，避免高同质化。

📐 六、不同视觉的转化作用

⚠️ 流量异常处理

提升销量的三板斧之三：流量异常处理。流量异常会导致商品在对应站点被屏蔽，请第一时间处理！

📌 流量异常初认识

流量异常会导致商品在对应站点被屏蔽，查看路径：卖家中心 - 商品管理 - 商品价格申报，关注"流量严重下降""流量竞争力不足""流量即将下降"标签。

📌 流量异常处理流程

建议价格过低可能是错价同款，需及时申诉。正确反馈格式：SPU + 流量异常站点截图 + 查询/申诉需求。

📌 高价限流初步判断

限流会影响商品在对应站点屏蔽，查看路径：商家后台首页 - 商品上新生命周期 - 高价限流待处理，发现"高价商品限流中"标签需第一时间处理。

📌 高价限流常见误区

限流是按站点来的，不同地区站点的限流价格不同！绿色价格展示的是最低价格部分，实际需点击查看分站点建议价格，优先解除大站点（美国/英国/法国/西班牙）限流。

📌 高价限流常见误区（补充）
